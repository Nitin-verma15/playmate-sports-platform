# PlayMate Mobile App

This directory contains the React Native mobile application for PlayMate.

## Technology

- React Native
- Expo
- TypeScript

## Purpose

The mobile application provides the user interface for:

- User authentication
- Player profiles
- Sports game discovery
- Game creation and management
- Google Maps-based location discovery
- Joining and leaving games
- Waitlist management
- AI-assisted game search

## Development

From this directory, run:

```bash
npm install
npx expo start
