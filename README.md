# PlayMate

Hyperlocal Sports Player & Game Discovery Platform

## About

PlayMate is a college-level mobile application that helps users
discover, create, and join nearby sports games based on sport,
location, time, skill level, and available player slots.

## Tech Stack

- React Native + Expo
- Node.js + Express.js
- PostgreSQL
- Firebase Authentication
- Google Maps API
- GenAI API

## Project Structure

playmate-sports-platform/
├── mobile/      # React Native mobile application
├── backend/     # Node.js + Express REST API
├── database/    # PostgreSQL schema and migrations
└── docs/        # Project documentation

## Core Features

- User authentication and profiles
- Create and manage games
- Nearby game discovery
- Google Maps integration
- Join/leave games
- Waitlist and player dropout handling
- AI-assisted natural-language game search
